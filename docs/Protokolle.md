# Arbeitsprotokolle

Dieser Abschnitt dient als fortlaufendes Protokoll aller Arbeitssitzungen. Kopiere für jede neue Sitzung die Vorlage aus `README_Template.md`, füge sie hier ein und fülle sie aus. Die neueste Sitzung sollte oben stehen.

---

## Beispiel-Eintrag (zum Überschreiben)

### Session Metadata
- **Date:** YYYY-MM-DD
- **Start / End Time:** HH:MM–HH:MM
- **Facilitator / Note-taker:** Name
- **Participants:** Namen

### Objectives
- **Session goal:** Kurze Beschreibung des Ziels
- **Scope / Deliverables:** Erwartete Ergebnisse

### Context
- **Current project milestone:** Meilenstein
- **Related issues or tasks:** Verweise auf Aufgaben oder Tickets
- **Links (designs, tickets, docs):** URLs oder Pfade

### Agenda & Steps
1. Schritt 1
2. Schritt 2
3. Schritt 3

### Decisions & Rationale
- Entscheidung 1 – Begründung
- Entscheidung 2 – Begründung

### Outcomes
- **Completed work:** Was wurde abgeschlossen?
- **Partial progress / drafts:** Zwischenstände
- **Open questions:** Unklarheiten

### Risks & Blockers
- Risiko oder Blocker

### Follow-up Actions
- **Next tasks:** Nächste Aufgaben
- **Owners:** Verantwortliche
- **Due dates:** Fälligkeiten

### Artifacts
- **Commits / PRs:** Links oder IDs
- **Screenshots / recordings:** Pfade
- **Notes / documents:** Weitere Dokumente
